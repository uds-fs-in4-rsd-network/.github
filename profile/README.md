# `uds-fs-in4-rsd-network` — Master 1 RSD (Réseaux)

Organisation GitHub dédiée aux travaux académiques de l'Unité d'Enseignement **Réseaux (Niveau 4)** du **Master 1 Réseaux et Services Distribués (RSD)** à l'Université de Dschang (Pr Bomgni Alain Bertrand, 2026/2027).

- **Périmètre :** Travaux pratiques, guides de préparation, scripts de configuration et supports d'étude de l'UE Réseaux.
- **Cadre d'usage :** Captures et tests réseau limités strictement aux environnements et réseaux autorisés de TP.
